## 3. 실행 플랜

### Phase 0 — 이번 주 (₩0) : 검색 순위 + 전환 장치
1. **앱 이름 교체** (30자): `여권사진·증명사진 만들기 - Yei ID` (22자) 또는 `여권사진 증명사진 비자사진 - Yei ID` (23자). 키워드를 분리·선행, 브랜드 후행.
2. **짧은 설명** (80자): `여권사진·비자사진·운전면허·증명사진을 폰에서 1분. 큐넷 규격·용량 자동, 광고 없음, 사진은 기기 밖으로 안 나가요`
3. **자세한 설명 2,500~3,000자로 확장** — §4 키워드 클러스터 반영. 공무원·토익은 `verified=true` 전까지 언급 금지(미검증 규격 노출 = 반려 리스크 + 정책 위반 소지).
4. **태그 정리**: "디지털 액자" 제거 → 유틸리티/문서/취업 계열로 교체.
5. **스크린샷 4→8장 + 캡션**(§4) — 경쟁사 불만 직격 문구. 30초 시연 동영상은 Phase 1.
6. **웹사이트 등록**: privacy.html 호스팅 도메인을 랜딩(1페이지)으로 확장 → 네이버/구글 SEO + 파워링크 착지점. (현재 비어 있음)
7. **리뷰 12개 전부 답글** — 순위 신호 + 신뢰. 이후 신규 리뷰 48시간 내 답글 원칙.
8. **인앱 리뷰 요청 구현** — 저장 성공 토스트 직후, 2회째 저장부터, `@capacitor-community/in-app-review`. (코드 1시간)
9. **무료 횟수 5→2장** — 플레이북 레버①. 근거: 25설치·0구매 = 페이월 미도달. 최소한 "페이월 노출률" 집계부터 넣고 결정.
10. 시험 규격 `verified` 확정 작업 착수(MAINTENANCE.md TODO) — Phase 1 키워드 확장의 전제.

### Phase 1 — 2~6주 (₩0~5만) : 콘텐츠·시즌·리뷰 엔진
- **큐넷 선점**: "큐넷 사진 300×400 200KB 맞추는 법" 네이버 블로그 1편 + 쇼츠 1편. 검색 경쟁 거의 없음. 큐넷 정기 접수 일정(연 3회)에 맞춰 발행.
- **여권/비자**: "사진관 안 가고 여권사진 만들기 1분" 쇼츠·릴스 2편, 워홀/유학/미국비자 카페에 미국 2×2 규격(프리미엄 기능) 글 — 지불의사 높은 세그먼트.
- **취준**: 이력서·반명함 규격 글 1편(취준 카페).
- **프로모션 코드 이벤트**: 커뮤니티/블로그 댓글 이벤트 20~50개 — 리뷰 유도 문구는 금지(정책), "써보고 솔직 후기" 수준만.
- **시즌 캘린더**: 공무원 원서(1~2월, verified 후) · 큐넷(2·5·8월) · 토익(매월, verified 후) · 여름/겨울 방학 여권 발급 피크(6~7월, 12~1월).
- 리뷰 목표 14→30개. 5.0 유지보다 **개수**가 순위에 더 중요.

### Phase 2 — 게이트 통과 후 (₩15만 한도 테스트)
- **Google Ads 앱 캠페인** 일 ₩10,000 × 14일, 애셋 = 8장 스크린샷 + 30초 영상, 테마 키워드 "여권사진 어플/셀프 증명사진". 목표 CPI ≤ ₩800.
- **네이버 파워링크** "여권사진 어플" "셀프 여권사진" CPC 입찰 소액 병행(랜딩 필수).
