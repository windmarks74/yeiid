## 1. 3편(이력서)에 3개 — 표 **아래**에 붙인다

⚠️ README 계획은 "비교표의 각 줄에 링크"였다. **바꿨다.** 표가 공백으로 칸을 맞춘
고정폭 블록이라 줄 안에 링크를 넣으면 정렬이 깨지고 모바일에서 줄바꿈이 어긋난다.
표는 이 글의 무기이므로 건드리지 않고, 바로 아래에 링크 묶음을 둔다.

## 왜 이 방향으로만 걸었나

- **1↔2 는 양방향**, 3→1·2·4 는 **한 방향**이다. 3편이 비교표를 가진 허브라서
  들어오는 링크보다 나가는 링크가 많은 게 자연스럽다.
- 4편 → 3편만 걸고 4편 → 1·2편은 걸지 않았다. **편당 링크 1~2개를 넘기지 않는다** —
  글마다 자기 글 링크가 3~4개씩 붙으면 네이버가 보는 그림이 내부 링크 과다가 된다.
- 모든 글은 이미 본문 끝에 사이트 규격 페이지 링크를 하나씩 갖고 있다. 그게 우리의
  **유일하게 작동 중인 외부 백링크**이므로(README 참고) 이번에 추가하는 내부 링크가
  그 자리를 밀어내지 않도록 위치를 떨어뜨렸다.
