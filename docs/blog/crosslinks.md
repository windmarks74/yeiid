## 링크 방향을 이렇게 잡은 이유

- **여권 글은 받는 쪽이 아니라 주는 쪽이다.** 262회가 거기 있으므로 링크는
  **여권 → 사이트 · 여권 → 3편** 으로 나가야 트래픽이 움직인다. 반대로 걸면
  조회수 1~15짜리 글에서 262짜리로 보내는 꼴이라 아무것도 안 바뀐다.
- 3편이 비교표를 가진 **허브**라 나가는 링크가 많은 게 자연스럽다.
- 나머지는 **편당 1~2개를 넘기지 않는다.** 내부 링크 과다로 보이면 역효과다.
- 모든 글 끝의 사이트 링크는 **우리의 유일하게 작동 중인 외부 백링크**이므로
  (구글 색인이 2/10 에서 안 움직이는 이유) 이번 내부 링크가 그 자리를 밀어내지 않게
  위치를 떨어뜨렸다.
