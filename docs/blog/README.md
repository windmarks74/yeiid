# 네이버 블로그 — 현황과 계획

> 붙여넣기용 원고는 각 `NN-*.md` 의 `=== 본문 시작 ===` ~ `=== 본문 끝 ===` 사이.
> 이미지는 `img/` — 재생성은 `node scripts/make-blog-images.mjs`.
>
> **왜 블로그인가:** 깔때기에서 병목이 노출이고(방문→설치 76%는 더 올릴 여지가 없다),
> 구글 색인도 "발견됨 – 현재 색인이 생성되지 않음"으로 막혀 있다. 외부 링크가 0이기
> 때문이다. 블로그 글 본문의 사이트 링크가 **현재 작동 중인 유일한 외부 링크**다.
> 근거: `docs/funnel-2026-09-20.md`, `docs/marketing-strategy-2026-09-12.md`.

## 현황 (2026-09-20 기준)

| 편 | 주제 | 성격 | 반박 거리 | 발행 |
|---|---|---|---|---|
| 1 | 공무원 원서 | 1~2월 시즌 | 100KB → 350KB 미만 | ✅ 2026-09-20 |
| 2 | 큐넷 | 1~2월 시즌 (+2·5·8월) | 디지털이 안 되는 게 아니다 | ✅ 2026-09-20 |
| 3 | 이력서·크기 비교 | 상시 | 공식 규격이 아예 없다 | ✅ 2026-09-20 |
| 4 | 토익 | 상시 (접수 거의 매달) | 115×150px 은 10년 된 값 | ✅ 2026-09-27 |

**시즌 2 + 상시 2** 로 균형이 맞았다. 3·4편은 "떠도는 숫자에 근거가 없다"로 논리가 같다.

## 발행 리듬

1~3편이 같은 날 올라갔다. **문제되는 수준은 아니다** — 스팸 패턴은 하루 10~30개 이상에
중복·자동 생성 글이고, 우리 글은 주제가 전부 다르고 사이트와도 문장이 다르며 직접 만든
이미지가 편당 3장씩 들어간다. 되돌릴 필요 없다(올렸다 지우는 게 더 부자연스럽다).

**앞으로가 중요하다: 주 1~2회 리듬을 유지한다.** 네이버는 지속성을 본다.
4편은 3편 발행일 기준 2~3일 뒤.

## ✅ 상호 링크 — 4편 발행(9/27)으로 열렸다 ▸ `crosslinks.md`

**글 사이 상호 링크.** 발행글을 여러 번 고치는 것보다 전부 올린 뒤 한 번에 넣는다.

> 붙여넣기용 문구와 삽입 위치는 **`crosslinks.md`** 에 있다. 네이버 글 주소 4개만 채우면 된다.
> 3편은 계획을 바꿨다 — 표 줄 안이 아니라 표 아래에 묶어서 넣는다(고정폭 정렬이 깨진다).

- 3편(이력서) 비교표 — **공무원** 줄 → 1편, **큐넷** 줄 → 2편, **토익** 줄 → 4편
- 1편(공무원) 끝 — "큐넷도 준비하신다면" + 2편
- 2편(큐넷) 끝 — "공무원 원서도 넣으신다면" + 1편
- 4편(토익) 본문의 "일반 증명사진" 언급 → 3편

내부 링크는 체류를 늘리고, 네이버가 "연결된 콘텐츠를 가진 블로그"로 인식한다.

## 글 쓸 때 지킨 규칙

1. **반박 거리를 하나 잡는다.** 확실히 틀린 통념이 있어야 기존 상위 글을 이길 명분이 생긴다.
2. **사이트 페이지와 문장을 다르게 쓴다.** 그대로 복사하면 중복 콘텐츠가 되어
   우리 `/gosi`, `/qnet` 등과 서로 순위를 갉아먹는다. 수치만 같고 문장은 새로.
3. **단정하지 않는다.** 근거가 약한 값은 "접수 시 공지를 한 번 더 보라"로 처리한다.
   특히 3·4편은 "남들이 단정해서 틀렸다"는 글이라, 우리가 단정하면 논지가 무너진다.
4. **수치는 `src/usage.ts` 와 맞춘다.** 규격이 바뀌면 이 원고들도 같이 고친다.
   `check-spec-sync.mjs` 는 블로그 원고와 PNG 안의 글자를 검사하지 못한다.
5. 네이버 에디터는 마크다운을 해석하지 않는다 → 원고는 일반 텍스트.
6. 이미지는 **파일 업로드**만 된다. 외부 URL 연결은 쓰지 않는다(우리가 파일을 바꾸면
   글이 깨지고, 네이버가 "이 블로그의 이미지"로 쳐주지도 않는다).
